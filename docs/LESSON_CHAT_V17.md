# v17 — Чат учебной пары

Добавлен realtime-чат через ASP.NET Core SignalR.

## Доступ
- Admin: любой существующий урок.
- Teacher: только уроки, где он назначен преподавателем.
- Student: только уроки своей учебной группы.
- Parent: доступа нет.

## Backend
- `/hubs/lesson-chat` — SignalR Hub.
- JWT передаётся через `access_token` для WebSocket/SignalR.
- Сообщения сохраняются в `lesson_chat_messages`.
- Загружаются последние 100 сообщений при входе.
- Лимит сообщения: 2000 символов.

## Frontend
- `LessonChatPage.tsx` подключается к Hub.
- Автоматическое переподключение.
- История + realtime сообщения.
- Чат доступен из текущей пары преподавателя и студента.

## Важно
Для frontend требуется `npm install`, потому что добавлен пакет `@microsoft/signalr`.
Полная компиляция не заявляется без установленного SDK/node_modules.
