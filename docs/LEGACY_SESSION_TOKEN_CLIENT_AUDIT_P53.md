## Migration safety note

The login flow in `LocalAuthController` issues JWT access tokens and `/api/auth/me` resolves the current user from JWT claims. However, the legacy MyStat proxy endpoints still resolve users through `RegistrationSessions`/`TelegramId`, while the frontend has remaining `sessionToken` dependencies. Replacing these mechanically or adding `[Authorize]` without migrating callers would break functionality. P53 does not claim this security blocker is fixed.
