# Jornal v22

## Реализовано

- Административный Audit Log UI.
- Создание и скачивание backup ZIP.
- Восстановление backup ZIP с проверкой manifest и SQLite `PRAGMA integrity_check`.
- Перед restore создаётся safety copy текущей БД.
- Единый экран текущей пары преподавателя: тема, посещаемость, быстрые переходы к ДЗ/оценкам, материалам, онлайн-паре, чату, доске и Code Lab.
- Frontend nginx reverse proxy для `/api`, `/hubs` и `/health`.
- Production-oriented Docker Compose с healthcheck и persistent volumes.
- GitHub Actions: backend restore/build, frontend lint/build, Docker builds.
- `.env.example` без секретов.

## Restore

1. Администратор открывает «Аудит и backup».
2. Выбирает ZIP, созданный Jornal.
3. Backend проверяет пути, manifest и целостность SQLite.
4. Текущая БД сохраняется как safety copy.
5. Восстанавливаются база и `storage/attachments`.
6. Backend рекомендуется перезапустить.

## Ограничения

- Yjs/Hocuspocus в v22 не добавлялись.
- MyStat/Telegram не удалялись.
- Полноценный E2E-набор пока не добавлен; CI проверяет сборку.
