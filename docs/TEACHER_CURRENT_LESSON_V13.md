# Teacher current lesson — v13

## Что теперь входит в рабочую пару преподавателя

- список ближайших занятий преподавателя;
- автоматическое определение занятия, которое идёт сейчас;
- открытие текущей пары одним действием;
- просмотр группы и студентов;
- установка темы пары;
- сохранение посещаемости;
- выставление оценок;
- создание домашнего задания;
- просмотр сданных работ;
- обязательный AI-тест из 3 вопросов после проверки;
- финальная оценка преподавателя;
- переход к материалам конкретной пары;
- запуск/завершение онлайн-пары через LiveKit.

## Online lesson

Backend создаёт отдельную комнату для занятия и выдаёт JWT LiveKit только:

- преподавателю этой пары;
- студенту, который состоит в группе пары;
- администратору.

Если LiveKit не настроен, API не делает вид, что онлайн-пара запущена: возвращается HTTP 503 с инструкцией по настройке.

Необходимые переменные:

```env
LIVEKIT_URL=http://localhost:7880
LIVEKIT_API_KEY=...
LIVEKIT_API_SECRET=...
```

Студентский интерфейс подключения к активной комнате будет следующим отдельным шагом; серверная авторизация участника уже подготовлена.
