# v14 — студентская онлайн-пара и родительская посещаемость

- Студент видит текущую пару через `/api/lessons/student/current`.
- Если преподаватель запустил LiveKit-комнату, студент получает кнопку подключения.
- Токен LiveKit выдаётся сервером только студенту из группы занятия.
- Родитель получает список связанных детей и посещаемость выбранного ребёнка.
- Родитель не получает права редактирования посещаемости.
